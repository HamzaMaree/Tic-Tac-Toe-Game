# Tic-Tac-Toe-Game
This Tic-Tac-Toe game is made by Java & JavaFX . You can play with the computer or with your friend !

# How to play 
* One User : Select one player , then select what role you want to play (X or O) , then start playing 
<img width="493" height="524" alt="image" src="https://github.com/user-attachments/assets/4c64d405-010e-4f1b-a055-0293841371e9" />


* Two Users: Select two players. X Player will start playing, Then X Player and so on.
